 📋 CUSTOMIZATION GUIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  To Add Custom Tailwind Classes:
  ───────────────────────────────

    1. Open: asssets/css/input.css

    2. Add your custom classes in @layer components section:

       @layer components {
           .btn-primary {
               @apply px-4 py-2 bg-blue-500 text-white rounded-lg 
                      hover:bg-blue-600 transition-colors;
           }

           .card-custom {
               @apply bg-white rounded-lg shadow-md p-6 
                      border border-gray-200;
           }

           .hero-section {
               @apply min-h-screen bg-gradient-to-r from-blue-500 
                      to-purple-600 text-white flex items-center;
           }
       }

    3. Run build command:
       npm run build:css

    4. Your new classes are now available in tailwind.css
       <div class="btn-primary">Click me</div>
       <div class="card-custom">Content</div>

  To Customize Theme Colors:
  ──────────────────────────

    1. Open: tailwind.config.js

    2. Modify the theme section:

       theme: {
           extend: {
               colors: {
                   'primary': '#3a7bd5',
                   'secondary': '#4a90e2',
                   'tertiary': '#2a6bc5',
               },
           },
       }

    3. Run build command:
       npm run build:css

    4. Use in HTML:
       <button class="bg-primary text-white">Primary Button</button>
